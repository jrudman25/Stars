# Stars

A randomly generated night sky with twinkling and shooting stars.

![Stars night sky demo](./images/stars-demo.gif)

## Features

- Adjustable star count, size, and twinkle speed
- Adjustable shooting star count and speed
- One-click sky regeneration
- Immersive controls that remain subdued until used
- Fullscreen viewing and reduced-motion support

## Development

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```
